# my-mvp

Full stack: React + FastAPI + PostgreSQL + Redis

## Run

```bash
docker-compose up
```

## Services

- Frontend: http://localhost:5173
- Backend: http://localhost:8000
- API Docs: http://localhost:8000/docs
- PostgreSQL: localhost:5432
- Redis: localhost:6379

## Stop

```bash
docker-compose down -v
```
