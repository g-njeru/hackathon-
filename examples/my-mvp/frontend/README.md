# my-mvp/frontend

React + Vite + Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Opens at http://localhost:5173

## Environment

- `VITE_API_URL` — Backend URL (default: http://localhost:8000)
- `VITE_USE_MOCK` — Use mock data (default: true)

## Build

```bash
npm run build
```

Output in `dist/`.
